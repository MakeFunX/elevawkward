elevawkward coins a new English word for the stiff, eyes-on-the-floor silence of sharing a lift with a stranger. The word blends "elevator" and "awkward" into a single noun for that very specific quiet. The program writes the word and its one-line definition to /output/entry.txt.

## Run it

```sh
python3 main.py
```
